Чтобы отправить новые изменения в коде на GitHub, вам нужно выполнить стандартную цепочку из трех команд в терминале.

Добавьте измененные файлы в индекс GitЭта команда находит все новые и измененные файлы в проекте и готовит их к сохранению:
git add .

Зафиксируйте изменения (создайте коммит)Обязательно напишите в кавычках короткое пояснение, что именно вы изменили в коде (например, "Добавил обработку исключений" или "Исправил баг в TcpClient"):
git commit -m "Опишите ваши изменения здесь"

Отправьте изменения на GitHub Загрузите ваш коммит в удаленный репозиторий:
git push


обновляет текущую ветку данными из связанной с ней удаленной ветки (самый частый сценарий).
git pull

Этот флаг скачивает изменения, а ваши локальные (еще не отправленные на сервер) коммиты аккуратно переносит на самый верх истории, сохраняя её красивой и линейной.
git pull --rebase

автоматически берет скачанные изменения и вливает их в вашу текущую локальную ветку.
git merge

связывается с удаленным сервером и скачивает новые данные (коммиты, файлы, ветки), но ничего не меняет в ваших рабочих файлах. Это безопасный этап «разведки».
git fetch
